# accuratep0wer · Personal projects

A personal project page with a portrait, contact links, and project snapshots.

- Homepage: AI Academic Lineages, Hanzi Token Lab and Quyi Genealogy summaries, screenshots, live demos, and source links.
- `ai-lineage/`: the bilingual AI academic-lineage explorer and its derived public dataset. Research archives and local audit files are excluded; contribution drafts stay in the visitor's browser. See its README for source attribution and coverage limits.
- `project-snapshots/2026-11-18/ai-lineage.png`: the dated AI Academic Lineages screenshot.
- `project-snapshots/2026-11-14/`: fixed screenshots, summaries, and source revisions. These dated records are separate from the live demos.
- No API credentials or private résumé documents are included.

GitHub Pages publishes the root of `master` at <https://accuratep0wer.github.io/zfz.github.io/>.

For a local preview, run `python -m http.server 8000 --bind 127.0.0.1` from the repository root. This is a static HTML, CSS and JavaScript site; no build step or API key is needed.

The repository originally used Jon Barron's academic website template. The current homepage presents accuratep0wer's own projects and portrait. Template biographical content and publication listings are no longer displayed.
